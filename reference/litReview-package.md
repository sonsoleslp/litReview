# litReview: Summarizing Graphs for Literature Reviews

Provides functions to summarize and visualize categorical data from
literature reviews. Generates bar charts, waffle charts, donut plots,
co-occurrence heatmaps, trend charts, and world maps for reporting study
characteristics across multiple publications.
