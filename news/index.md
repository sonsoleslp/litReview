# Changelog

## litReview 1.0.0

- Initial CRAN release.
- Plotting functions for literature-review data:
  [`reviewBar()`](https://sonsoles.me/litReview/reference/reviewBar.md),
  [`reviewStackedBar()`](https://sonsoles.me/litReview/reference/reviewStackedBar.md),
  [`reviewHistogram()`](https://sonsoles.me/litReview/reference/reviewHistogram.md),
  [`reviewWaffle()`](https://sonsoles.me/litReview/reference/reviewWaffle.md),
  [`reviewPie()`](https://sonsoles.me/litReview/reference/reviewPie.md),
  [`reviewOverlap()`](https://sonsoles.me/litReview/reference/reviewOverlap.md),
  [`reviewUpset()`](https://sonsoles.me/litReview/reference/reviewUpset.md),
  [`reviewTrend()`](https://sonsoles.me/litReview/reference/reviewTrend.md),
  [`reviewMap()`](https://sonsoles.me/litReview/reference/reviewMap.md),
  [`reviewAlluvial()`](https://sonsoles.me/litReview/reference/reviewAlluvial.md),
  [`reviewTreemap()`](https://sonsoles.me/litReview/reference/reviewTreemap.md),
  [`reviewMatrix()`](https://sonsoles.me/litReview/reference/reviewMatrix.md),
  [`reviewTree()`](https://sonsoles.me/litReview/reference/reviewTree.md),
  and the summary-table function
  [`reviewTable()`](https://sonsoles.me/litReview/reference/reviewTable.md).
- Colour arguments accept a vector of colours or the name of an
  ‘RColorBrewer’ palette.
- [`reviewMap()`](https://sonsoles.me/litReview/reference/reviewMap.md)
  resolves country names, common aliases, and ISO 2-/3-letter codes, and
  warns about values it cannot match.
- Interactive ‘Shiny’ application launched with
  [`run_app()`](https://sonsoles.me/litReview/reference/run_app.md).
